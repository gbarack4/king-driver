# Drivecab Driving School Website

A responsive static website for Drivecab Driving School, built with HTML, CSS and JavaScript.

## Files

- `index.html` — website structure and content
- `styles.css` — colours, layout and responsive design
- `script.js` — instructor filters, mobile menu and booking-form interactions
- `assets/driving-lesson.jpg` — website image

## Run locally

Open `index.html` in a browser. For a local web server, run:

```bash
npx serve .
```

## Push to GitHub

1. Create a new empty repository on GitHub.
2. Extract this ZIP and open the folder in Terminal.
3. Run:

```bash
git init
git add .
git commit -m "Add Drivecab Driving School website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

## Deployment

This static website can be hosted on GitHub Pages, AWS Amplify, Cloudflare Pages, Netlify or any standard web server.

For GitHub Pages, open the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/root`, then save.
